# 新对象架构实施路线

按PR16从零推进，旧原型与PR17不构成兼容或实现前置条件。

| 阶段 | 当前工作与退出条件 |
| --- | --- |
| N0 协议与格式 | 已有有界模型、独立历史判定及第一版严格格式；冻结预算和真实API，保持语义与实现一致 |
| N1 单库真实提交 | 新Rust权威、S3 adapter、native gate、强读/取消/接管已写入候选；须完成精确单元覆盖、真实S3故障、AWS Standard和全计算丢失验收 |
| N2 多库接入 | 名称目录、用户鉴权、HTTP/Node SDK、路由准入、并发创建、独立reader与公平调度 |
| N3 可持续存储 | 更大规模分段索引、增量恢复、compaction、pin、GC、PITR；验证多轮回收安全及总成本收敛 |
| N4 首发 | MB/GiB、长尾/热点/唤醒风暴、长运行、故障域、性能恢复成本与运维；另行获准后用非关键数据试运行 |

本轮不以原Raft的538测试或旧SLO观测认证新实现。实际门禁失败保持阻塞，缺失环境记NOT_RUN；不将一个小规模子集包装为整个阶段完成。
