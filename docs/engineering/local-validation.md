# 本地验证与精确候选源码绑定

日期：2026-11-05。适用范围：维护者明确授权以本地验证作为合入依据的工作；不修改现有远端 workflow 或分支保护。本文不会把没有执行的远端 CI 记录为通过。

## 合入依据

本地验证必须对应将要合并的候选代码，不能沿用旧提交的成功报告。运行时改动仍执行原有完整单元、精确覆盖率、真实依赖与受影响故障合同；存储/共识改动不能只运行单元。独立的工具脚本改动执行完整 tooling 单元与覆盖率，并明确没有重跑数据库实验。文档改动检查内容与链接。缺失工具链或依赖导致的步骤标记 `NOT_RUN`，不合并未经所需验证的运行时变更。

新增 `scripts/source_manifest.py` 只检查**源码身份**，不是测试执行器、测试结果证明或自动合并工具。成功的 source verify 不能替代退出码、覆盖率报告、原始故障历史与构建输入证明。

## 使用

在隔离的、无未提交修改和非忽略新文件的完整工作区内运行。候选代码应先提交到本地分支；不要在测试中修改这个工作区。证据存放在仓库外的独立目录。

```bash
set -eu
EVIDENCE_DIR=$(mktemp -d)
python3 scripts/source_manifest.py capture "$EVIDENCE_DIR/source-before.json"

# 在这里运行当前候选所需的独立门禁，保留每项原始日志和退出码。
# 本段示例没有替你运行数据库验证，也不是“完整验证”的单条替代命令。

python3 scripts/source_manifest.py verify "$EVIDENCE_DIR/source-before.json"
```

`capture` 记录 HEAD commit、tree、所有 Git 已跟踪文件的相对路径、模式、blob ID、字节数和 SHA-256，以及规范 JSON 清单的 SHA-256。清单用独占创建写入，已有记录不会被覆盖；文件较大或写失败留下的部分文件不能作为成功证据，需保留失败现场并在新证据目录重跑。

每个实际文件的原始字节必须匹配 Git blob，不只相信 `git status`。因此 `assume-unchanged` 隐藏的修改和 `core.filemode=false` 隐藏的执行位变化也被拒绝。复制中的文件变化、缺失文件、符号链接、子模块、冲突 stage、重复路径、脏源码及未跟踪源文件均不能被静默忽略。当前格式要求 SHA-1 Git 仓库；实际内容另外计算 SHA-256。UTF-8 路径中的空格与中文支持，非规范路径和控制字符拒绝。

`verify` 校验清单结构与摘要，再重新检查当前仓库。即使文件 tree 相同而 HEAD 已变更，也不会自动复用先前报告。更换候选后应使用新的记录，而不是改写旧 manifest。

## 保留的验证边界

此检查假设运行者及工作区受信，不是防恶意构建进程的沙箱或供应链签名系统。它不能发现两次检查之间被更改又恢复的瞬时输入，也不捕获未跟踪且被忽略的输入、外部缓存、依赖、编译器、环境变量或原生库。隔离构建、锁文件、二进制/工具链摘要、实际 profile 合并清单仍需独立记录。依赖忽略目录中的自定义源码作为产品输入时，应先规范跟踪或另外纳入构建清单，不能宣称本工具已经覆盖。

使用受信 Git 配置，不在同一工作目录运行并发编辑；启用 checkout 过滤器或换行转换导致原始字节不等于 blob 时，本工具保守拒绝。工具的文件模式测试在 POSIX 环境执行，未声称 Windows 工作区验收。

合并前重新读取远端 PR head 和 main。head 必须与实测候选一致；base 改变时先审查差异，受影响门禁重新执行。合并调用绑定预期 head，不强制推送，不跳过分支保护。GitHub 合并产生不同 commit 时，应核对最终 tree 与已验证候选的关系，不能事后篡改原 manifest。

## 本轮实测

本轮只新增该工具、对应测试和文档，没有修改 Rust/SDK 运行时、依赖锁文件、容量常数或 workflow。六个既有 tooling 源文件/测试文件逐个核对 Git blob 后参与回归；本轮 checkout 范围为 tooling，并非重新构建完整 SCAP 服务。

- Python 3.13.5、coverage.py 7.13.3、POSIX Linux；不同于仓库 CI 锁定的 coverage.py 7.10.6，本轮未改变锁定版本。

- 全部 tooling 85 项测试通过；四个脚本 481/481 statements、228/228 branches。
- 没有执行本轮 Rust 构建、Rust 覆盖率、Node SDK 或数据库故障实验，历史报告仍保持原提交身份。
